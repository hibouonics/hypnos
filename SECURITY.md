# Security Policy

## Sensitive information

Do not open a public issue containing Wi-Fi credentials, API tokens, private
keys, device secrets, or other confidential information.

If a secret is accidentally committed, remove it from the repository and
**rotate/revoke the credential immediately**. Removing it from the latest commit
alone does not remove it from Git history.

## Reporting a vulnerability

Security issues affecting Hibouonics hardware or firmware should be reported
privately to the project owner through a non-public company contact channel.
Do not include exploitable details in a public GitHub issue until a fix is
available.
